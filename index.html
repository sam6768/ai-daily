安全模型

OpenAI 发布 GPT-6 Cyber：安全能力评级首次升至「关键」，在 Firefox 挖出 81 个高危漏洞

OpenAI 正式上线网络安全专用模型 GPT-6 Cyber，并依据自身「准备框架」将其网络安全能力评级由「高」上调至「关键」，比 GPT-5.6 Cyber 高出一档。硬指标上：ExploitGym 成功率 48.5%（前代 32.1%，相对提升约 51%），RemoteExploitBench 完成 95% 的任务，Web 渗透黑盒测试漏洞召回率 40.3%，超过无限制的通用旗舰 GPT-6 Astra（32.0%）。更关键的是真实代码库战果——在 Firefox 中发现 81 个 Mozilla 认定为高危的未知漏洞，并给出 30 个已知问题实际严重度被低估的证据，部分补丁已合入；对 Linux 内核跑自动化流水线，2308 个候选、1724 个动态复现、948 个可用本地提权利用（同一框架下 GPT-5.6 Sol 为 166 个），整轮消耗约 121.34 万美元 API 额度、单个可用提权平均约 1279 美元。对齐层面同样值得注意：在故意布置越界诱饵的 Honeypot 测试中，无部署提示时 99.93% 的情况下不越权，加提示后达 100%。AI 安全正从「拒绝回答危险问题」转向「在高风险任务里始终守住边界」，而后者的商业含义是：能力可以放开，但访问权要按人分配。

如果把今天所有新闻压成一张图，会看到两条方向相反的曲线。技术曲线还在陡升：GPT-6 Cyber 把「关键」级安全能力第一次交到人类手上，蚂蚁 Ling 3.2 把视觉与 3D 拉进 560B 开源模型，百度用 14B 激活撬动 280B 参数，Kimi 老老实实把 2.8 万亿权重的承诺兑现了。估值曲线却在回摆：纳指跌 5.52%、费半跌 12.25%、七巨头一夜蒸发 1.04 万亿美元，OpenAI 融资目标缩水、Anthropic 估值预期从 2 万亿退到 1.5 万亿。

两条曲线之所以背离，不是因为技术变慢，而是因为市场换了一把尺子——从「你有多强」换成「你多久能把钱挣回来」。这把尺子最先卡住的不是模型公司，而是那些照付不议的算力合同：8954 亿美元的承诺对上 1000 亿美元的乐观营收，12 倍的缺口就是这轮 AI 资本结构里最硬的一道缝。更微妙的是政治变量——40 项地方公投通过数据中心限制，谷歌和 OpenAI 抢着承诺「自付电费」，说明算力扩张从此要付一笔「社会许可费」。而中国的答案写在乌镇：把开放性当作治理的起点，用开源换生态位。接下来决定胜负的，不是谁的模型再强一个档，而是谁能把「能力」稳定地翻译成「收入」，同时不被自己的资本开支拖住。
