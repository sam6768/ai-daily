模型发布

OpenAI 发布 GPT-6.2 Astra 与 Sol 双模型：首个触及「自我改进 High」阈值的对外发布模型

Anthropic IPO 前夜，OpenAI 上线两款新模型并同步接入 ChatGPT Work、Codex 与 API。旗舰 GPT-6.2 Astra 面向金融建模、科学研究等复杂专业场景，在多步骤专业工作基准上较 GPT-6 Astra 高约 5.2 分，较 Claude Fable 5.2 高 5.5 分而成本仅为其 5%；API 定价每百万 token 输入 8 美元、输出 40 美元，较上代下调 20%，缓存输入再降 60%，上下文窗口 105 万 token。轻量的 Sol 在编程基准上仅落后 Astra 0.5 分、成本约为其五分之一，日常任务基准已超过上代旗舰。更值得记录的是安全评级：Astra 是 OpenAI 首个达到「AI 自我改进 High 阈值」的对外发布模型，两款模型均触及网络安全能力 Critical 阈值，高风险协助将被更严格拦截。同日还推出了面向法律行业的 Astra for Law，在覆盖 24 个法律领域的评测中位列第一。旗舰与次旗舰只差 0.5 分、价格差五倍——当能力差距收敛到小数点后，定价表就是新的产品发布会。

微软 AI 负责人苏莱曼在 Ignite 大会一口气发布 7 款自研专用模型，覆盖编码、网络安全、图像生成与语音。旗舰编码模型 MAI Code 2 官方口径达 GPT-6.1 Sol 编码性能的 98%、价格为其 40%，达 Claude Opus 5.5 性能的 96% 而成本仅为其 5%，可跨多文件理解整个软件项目；轻量的 Code 2 Flash 为 1379 亿参数 MoE，53GiB 检查点可在本地单机运行；网络安全模型 MAI Cyber 2 Flash 在某安全基准上击败 GPT-6 Astra，每任务成本不到后者的 2%，将先向小部分客户开放。硬件侧，第二代自研加速器 Maia 200 已量产，每瓦 token 数提升 1.7 倍。苏莱曼明确说企业一直在抱怨 token 支出飙升，微软的承诺是「最佳性价比」并允许企业在 Azure 内用自有数据微调部署。需要留意的是部分对比基于自测基准与促销价，且企业态度尚未经市场验证。微软不再只做 OpenAI 能力的转售方——把自研模型压进 Copilot 的工作流，实质是在云和工具之间建立自己的模型池与定价权。

训练治理

中国头部模型集体收剑：主动削弱网络攻击能力，监管约束前移到训练环节

彭博社报道，中国几家头部模型厂商在新模型中有意削弱网络攻击能力：阿里的 Qwen4-Max 在训练数据中过滤了可用于网络攻击的材料、并暂未开放权重，用户拿不到一个可自行去除审查的版本；腾讯混元则把漏洞利用生成类数据剔出了训练流程。共同点是「攻守分离」——攻击能力被刻意削弱，而漏洞检测、安全审计这类防御能力被保留。报道将此与监管背景相联系：《中国禁止出口限制出口技术目录》拟新增的 40 项技术中，AI 领域占 23 项，「AI 驱动的恶意代码生成与变异技术」拟列入禁止出口。这与大洋彼岸的动作形成呼应：OpenAI 的 GPT-6.2 同样触及网络安全 Critical 阈值并收紧高风险协助，中美两条路径不同，但都在把安全边界从发布后的系统卡，前移到训练数据与训练目标本身。当「能不能下载一个无审查版本」成为模型设计决策，开源与闭源之争就多了一层安全治理的维度——权重可控性本身正在变成合规工具。

工信部启动 AI 应用服务商培育专项行动；8 省市获批 6G 创新发展部省协同试点

工信部办公厅印发通知，启动人工智能应用服务商培育专项行动，提出到 2026 年底服务商资源池突破 2000 家、2027 年底不少于 3000 家——被视为政策重心从「拼模型」转向「拼交付」的直接信号。同期工信部同意北京、河北、上海、江苏、浙江、安徽、湖北、广东 8 地开展 6G 创新发展部省协同试点，围绕新型终端、关键器件、操作系统、卫星互联网等 6G 关联产业，面向沉浸式通信、工业制造、具身智能、低空经济、智慧海洋等场景探索应用。地方层面，福建印发「人工智能+」行动方案（2026—2028 年）并设立省人工智能产业基金；广东省数字政府「十五五」规划提出培育光通信芯片、光传感芯片产业集群。算力的评价体系也在换尺子：工信部方案提出到 2030 年建成国家级零碳工厂与零碳算力设施 500 个左右，竞争点从「机柜多、电价低」转向「绿电足、碳账清」。从模型补贴转向服务商资源池，意味着政策制定者已经把瓶颈定位清楚了：技术不缺，缺的是把技术装进行业流程的那一公里。

合规要求

苹果中国区 App Store 把 AIGC 备案变成必填项：现有应用须在明年 1 月底前补齐

苹果中国区开发者后台已将生成式 AI 服务的合规证明升级为必填项：上架应用若涉及 AIGC 功能，须提交服务声明、备案号与安全评估证明；调用第三方大模型的应用，还需上传算法备案号与授权协议。新应用立即执行，存量应用须在 2027 年 1 月底前补齐，否则面临下架风险。这是平台层第一次把生成式 AI 合规从「建议项」变成「准入项」，意味着此前只在监管文件里的备案要求，如今经由分发渠道直接传导到每一个开发者。海外侧的治理同样在细化：爱尔兰监管机构叫停马斯克旗下 AI 代理收集用户数据训练模型；联合国在日内瓦就可自主选择并攻击目标的武器系统展开谈判，推动建立有约束力的国际规则；美国商务部把芯片管制从实物延伸到远程算力访问后，中国商务部回应称若美方一意孤行将采取反制措施。合规正在从年检变成入口——对开发者而言，算法备案号正在成为和 ICP 备案一样的默认前置条件；早补齐是成本，晚补齐是下架。

今天最耐人寻味的，是同一天出现的三种「收剑」姿态。

OpenAI 在系统卡里第一次给对外发布的模型标上「自我改进 High」、网络安全「Critical」，同时把单任务成本砍到上代三分之一——能力封顶、价格下探、风险加锁，三件事一起做。中国头部模型则从训练数据源头过滤攻击类材料，监管的约束从「事后处罚」前移到了「训练环节」。加州干脆把失控超过 80 次的智能体测试写进了诉状。
