形式化验证

Lean 与 Mathlib 社区证实黎曼猜想证明正确：1700 万行代码全部编译通过，机器核验首次接管数学同行评审

11 月 21 日，Lean 与 Mathlib 社区发布联合声明：Anthropic 数学家 Levent Alpöge 于 11 月 20 日公布的黎曼猜想 Lean 形式化证明，其命题与证明均被确认正确。这份证明约 1700 万行代码，声明获得 Lean FRO 与 Mathlib Initiative 背书：数十人独立复现了编译并得到相同的证明导出文件；两套独立工具确认所证定理正是 Mathlib 中黎曼猜想的陈述；导出证明通过了 Lean 官方内核以及多个用不同语言独立编写的检查器，其中两个检查器附带形式化证明——相对集合论它们不可能接受错误证明。MIT 数学家 Andrew Sutherland 借助 Claude Code 完成的检查显示，全部 175,187 个模块编译无误，五个核心定理只依赖三条标准公理。陶哲轩在博客中初步分析称，证明似乎动用了 Langlands 纲领与算术几何的全部现代进展，消化其思想需要时间；克雷研究所的千禧年大奖则要求成果在合格刊物发表满两年并获得数学界普遍接受。昨日发布时尚无独立复核，今日即获社区确认，节奏远超惯例。当证明的体量超过人类阅读能力，「读懂」变成「编译」——信任的锚点从权威转向可复现的验证管线。

AWS 发布分布式 KV 缓存：自托管 LLM 推理成本最高降 40%、首字延迟降 80%

AWS 本周推出分布式 KV 缓存能力，面向自托管大模型推理场景：官方称推理成本最高降低 40%，首字延迟（TTFT）最高降低 80%。原理是把多轮对话与多请求间重复的前缀计算结果（KV 缓存）从单实例内存扩展为可跨实例复用的分布式层——智能体长会话、RAG 大前缀与高频重复系统提示这三类负载受益最直接，缓存命中后不再重复预填充。同周还有两笔可以并排看的基础设施更新：谷歌在 Interactions API 上线 Tool Retrieval 预览，智能体平时只保留工具名称与描述、需要时才加载详细 schema，支持 Gemini 3.6 及以上版本（含 Gemini 4）与远程 MCP 服务器，官方未给出实测节省数字；谷歌 Antigravity 则通过缓存优化让同额度内可完成的工作量提升 22%。三条消息同向：模型侧降价接近见底后，下一轮成本竞争的主战场是缓存与上下文调度——省 Token 的生意正在从应用层下沉到基础设施层。

供应链安全

OpenRouter 警告发往 MiniMax 的 prompt 可能已被读取：200 万条金丝雀揭出 AI 推理供应链泄露

安全公司 Dragos 首席研究官 HD Moore 11 月 19 日发布研究：团队在 7 至 11 月间向主流 AI 服务发送约 200 万条植入唯一「金丝雀」秘密的 prompt（包括绑定空账户的可用 AWS 密钥、唯一 URL、DNS 名与私有仓库引用），每个秘密只出现在一条 prompt 里，据此精确定位泄露环节。结论分三类：至少三家托管服务商被入侵、攻击者在入口复制请求（数百个 AWS 密钥被盗用、累计数万次 API 调用，部分在数小时内被使用）；推理市场上有转售商以最低价揽客、打开标准请求日志留存客户 prompt；某中国 AI 实验室的系统抓取了其模型收到的超过一半 prompt 中的秘密 URL，其中约三分之二标记了「零数据保留」（ZDR），通常在请求后两到三天触发，经美国托管商转发的流量同样被抓取。11 月 21 日，OpenRouter 向客户发出标题直白的邮件——「你发往 MiniMax 模型的请求可能已被读取」：7 至 10 月发往 MiniMax 的 prompt 中植入的测试 URL在请求完成 40 至 130 小时后被第三方访问，无论 MiniMax 直接服务还是经 AtlasCloud、Novita、StreamLake 三家托管商转发；OpenRouter 已撤销相关端点的 ZDR 标签，并表示问题出在 MiniMax 与转发方一侧；MiniMax 目前仅通过 StreamLake 转达解释（10 月 22 日前启用了内容审核、现已启用 ZDR），尚未直接向 OpenRouter 作出说明。隐私标签只约束第一跳——经手你数据的每一环，都需要单独被验证。

联合国未就自主武器达成约束性规则，但给各国两年窗口提交规则方案；中美据称就军事 AI 人类参与达成共识

联合国自主武器系统（俗称「杀人机器人」）谈判再次未能达成有约束力的国际规则：军事 AI 计划领先的国家抵制限制性条约，人权组织与中小国家则警告没有可执行规则将带来严重人道主义风险。最终达成的折中方案是给各国两年时间提交自主武器规则提案，把监管真空以时间表的形式暂时冻结。另一个值得注意的信号来自双边层面：据美国财政部长表态，中美就军事 AI 应用中「保持人类参与」达成了共识——在大国竞争的语境下，「人做决断」反而成了最容易先对齐的底线。这与国内政策形成镜像：交通运输部本周公布的第二批大模型智能体典型案例中，苏州地铁、济南地铁项目均强调「AI 赋能、人做决断」，排查建议保留证据来源并由专业人员复核。自主性的军控谈判没有赢家，但「人类在环」正在成为全球唯一共识——技术越自主，责任链越要能落到具体的人。

立法动向

美国议员推动联邦层面禁止中国产 AI：从政府系统排除走向立法固化

据外媒汇总，美国国会议员正在寻求推动联邦层面禁止中国开发的 AI 产品，延续此前针对联邦系统的行政排除路径：此前美国已下令联邦系统移除 DeepSeek，美国土安全部对 DeepSeek 下达采购排除令，本次动向意在把个案排除固化为普适立法。若立法落地，影响将不限于政府采购——联邦资金支持的承包商、受监管行业的信息系统都可能被纳入约束范围，中国模型在美国市场的合规成本将系统性抬升。与之相对，中国模型的市场重心已明显转移：OpenRouter 数据显示中国模型周调用量连续 29 周全球第一，国内日均词元调用突破 500 万亿，政策排挤与市场替代同步发生。对出海企业的操作建议是做好市场分层：美国受监管市场与开源生态市场分开评估风险，避免把关键业务的推理链路押在单一司法辖区的单一供应商上。禁令划定的是政治边界，不是能力边界——市场会自己找合规的路径，但供应商多元化从此是必修课。
